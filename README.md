# 김종민

**프로덕트 엔지니어** 김종민입니다.

프론트엔드를 중심으로 서비스를 개발하고 운영해 왔습니다. 기획과 디자인을 함께 검토하고, 더 나은 방법이 보이면 레퍼런스와 함께 의견을 제시합니다. 요청이 없어도 팀원이 반복해서 겪는 불편을 찾아 도구를 만듭니다.

[포트폴리오](https://guksu.github.io/GuksuJip/) · [블로그](https://guksulog.com) · [yung3152@gmail.com](mailto:yung3152@gmail.com)

표의 '자세히'는 포트폴리오에서 그 프로젝트를 소개하는 화면으로 이어집니다.
